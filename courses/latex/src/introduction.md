# LaTeX

LaTeX 文档排版、数学公式、图表与参考文献的学习笔记。

## 学习目标

- 熟悉文档结构、章节、目录与基础排版。
- 整理数学公式、图片和表格的排版方法。
- 记录参考文献、模板使用和编译过程中遇到的问题。
- 用练习文件验证排版效果，逐步形成自己的模板。
