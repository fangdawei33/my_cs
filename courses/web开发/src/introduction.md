# Web 开发

这门课先从正在使用的 **my_cs 网站**讲起。目标是能看懂自己的文件，知道改什么、在哪里改，以及改完怎样发布。

这里按 2026 年 11 月的项目结构编写；后续项目继续调整时，应以仓库中的实际文件为准。代码片段中标为“教学简化版”的内容，用于解释原理。

## 学完希望能做到

- 分清网站源码、构建工具和生成网页。
- 独立添加一篇笔记、一张图片和一门课程。
- 修改首页的文字、基本样式和展示素材。
- 用本地预览看效果，再提交、推送到 GitHub。
- 出现问题时，能找到相关文件和错误信息。
