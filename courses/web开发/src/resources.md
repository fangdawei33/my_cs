# 学习资料

本课程先围绕自己的 my_cs 项目学习，下面按笔记主题列出原始文档。遇到陌生语法时查相关部分即可，不要求一次读完所有页面。

## HTML、CSS 与 JavaScript

- [MDN：HTML 基础语法](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax)：对照元素、属性和文档结构。
- [MDN：什么是 CSS](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Styling_basics/What_is_CSS)：理解样式规则与页面外观。
- [MDN：什么是 JavaScript](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core/Scripting/What_is_JavaScript)：认识浏览器脚本的用途。

## Markdown 笔记与构建

- [mdBook：SUMMARY.md](https://rust-lang.github.io/mdBook/format/summary.html)：书籍目录的格式与层级。
- [mdBook：配置入口](https://rust-lang.github.io/mdBook/format/configuration/index.html)：查 `book.toml` 中的设置。
- [Node.js 官方入门](https://nodejs.org/learn/getting-started/introduction-to-nodejs)：理解运行在浏览器之外的 JavaScript。
- [npm：run-script](https://docs.npmjs.com/cli/v10/commands/npm-run-script/)：理解 `npm run` 与 `package.json` 脚本。这里链接 npm 10 的命令说明；实际环境版本以本机为准。

项目当前固定使用 mdBook 0.4.52。官方在线文档会持续更新，新版本选项是否适用，需要和项目实际版本核对。

## Git 与部署

- [Git 官方中文书：记录每次更新到仓库](https://git-scm.com/book/zh/v2/Git-%E5%9F%BA%E7%A1%80-%E8%AE%B0%E5%BD%95%E6%AF%8F%E6%AC%A1%E6%9B%B4%E6%96%B0%E5%88%B0%E4%BB%93%E5%BA%93)：工作区、暂存和提交。
- [GitHub：配置 Pages 发布源](https://docs.github.com/zh/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)：分支发布与 Actions 发布的配置入口。
- [GitHub：自定义 Pages 工作流](https://docs.github.com/zh/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)：构建产物与部署任务的衔接。
