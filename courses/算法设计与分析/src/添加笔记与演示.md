# 添加笔记与演示

## 文件放在哪里

```text
courses/算法设计与分析/src/
├── SUMMARY.md             # 左侧导航目录
├── 刷题.md                # 刷题总目录
├── problems/              # 每道题的 Markdown 笔记
│   ├── 01背包.md
│   ├── 区间分组.md
│   └── 最长公共子序列.md
└── demos/                 # 完整的 HTML 演示及其配套资源
    ├── 01背包问题动态规划算法可视化.html
    ├── 区间分组.html
    └── 最长公共子序列.html
```

## 加一个新演示

1. 把完整的 HTML 文件复制到 `src/demos/`，例如 `新题目.html`。
2. 如果它还引用同目录的 JS、CSS 或图片，也按原有相对路径复制进去。
3. 在 `src/problems/` 新建 `新题目.md`，记录题目、思路和代码。
4. 在 `src/SUMMARY.md` 的“刷题笔记”下添加子项，并在 `刷题.md` 的表格中补上入口。

目录链接示例：

```markdown
- [刷题笔记](刷题.md)
  - [新题目](problems/新题目.md)
```

## 在笔记里打开演示

从 `problems/` 中的笔记引用演示时，路径需要先返回上一层，再进入 `demos/`：

```markdown
[打开完整演示](../demos/新题目.html)
```

想在页内直接显示，可以复制现有题目页的 `iframe`，修改 `src` 和 `title`。`height` 控制显示高度；演示布局较宽时，用独立窗口阅读更方便。

现有演示使用 `sandbox="allow-scripts"`，允许动画脚本在独立页面中运行。演示中的全局样式与变量不会覆盖外面的笔记页面。

## 怎么发布

`src/` 内的 HTML、JS、CSS、图片会随 mdBook 构建复制到网站。原始 HTML 放在 `demos/` 中，左侧目录链接对应的 Markdown 笔记即可。

在项目根目录执行 `npm run dev`，先检查独立演示和笔记中的嵌入效果，再提交、推送到 GitHub。公开网站上的文件也会公开提供给读者访问。

当前三个演示会从网络加载 Tailwind 和字体。如果后续需要完全离线运行，可以再将这些依赖整理到本地。
