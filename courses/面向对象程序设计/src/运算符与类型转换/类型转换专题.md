#### 大题 1：温度单位转换系统（基础必考题）
工程背景
在气象监测和工业控制中，经常需要在摄氏度 (Celsius)、华氏度 (Fahrenheit) 和开尔文 (Kelvin) 之间进行单位转换。请设计一个Temperature类，支持三种温度单位之间的隐式 / 显式转换。
具体要求

类设计：

私有成员：double celsius（内部统一存储摄氏度）
转换构造函数：
Temperature(double c = 0.0)：从摄氏度构造
explicit Temperature(char unit, double value)：从指定单位构造（unit='F' 表示华氏度，'K' 表示开尔文）


类型转换运算符：
operator double() const：转换为摄氏度（隐式）
explicit operator double() const：转换为华氏度（显式）
explicit operator double() const：转换为开尔文（显式）


成员函数：
void print() const：输出格式：25.00°C = 77.00°F = 298.15K


转换公式：

华氏度转摄氏度：\(C=(F-32)\times\frac{5}{9}\)
开尔文转摄氏度：\(C=K-273.15\)
摄氏度转华氏度：\(F=C\times\frac{9}{5}+32\)
摄氏度转开尔文：\(K=C+273.15\)


测试要求：编写 main 函数，实现以下功能：

从摄氏度 25.0 构造温度对象
从华氏度 86.0 显式构造温度对象
从开尔文 300.0 显式构造温度对象
将温度对象隐式转换为 double（输出摄氏度）
将温度对象显式转换为华氏度和开尔文并输出


核心考点

转换构造函数与 explicit 关键字
多个类型转换运算符的重载
显式转换与隐式转换的区别

#### 大题 5：分数与浮点数转换系统（经典题）
工程背景
在科学计算中，有时需要用分数 (Fraction) 来精确表示有理数，同时需要支持分数与浮点数之间的转换。请设计一个Fraction类，支持分数的基本运算和与浮点数的转换。
具体要求

类设计：

私有成员：int numerator, denominator（分子和分母，始终保持最简形式）
构造函数：
Fraction(int num = 0, int den = 1)：从分子分母构造
explicit Fraction(double value)：从浮点数构造（精确到小数点后 6 位）


类型转换运算符：
operator double() const：转换为浮点数（隐式）


重载运算符：
Fraction operator+(const Fraction& other) const
Fraction operator*(const Fraction& other) const


私有辅助函数：
void simplify()：约分，将分数化为最简形式


成员函数：
void print() const：输出格式：3/4 = 0.75


测试要求：编写 main 函数，实现以下功能：

创建分数 f1 (1,2) 和 f2 (1,3)
计算 f1 + f2 并输出
计算 f1 * f2 并输出
将 f1 转换为浮点数并输出
从浮点数 0.6 构造一个分数并输出


核心考点

浮点数到类类型的转换构造函数
类类型到浮点数的类型转换运算符
分数的约分算法


考试答题技巧（类型转换大题满分必备）

内部统一存储原则：所有转换都基于一个内部统一的单位（如温度统一存摄氏度，时间统一存秒），这样转换逻辑最清晰，不容易出错。
explicit 关键字使用原则：
单参数构造函数默认加上 explicit，除非你明确需要隐式转换
类型转换运算符默认加上 explicit，除非是转换为 bool 或者最常用的单位


转换顺序：
其他类型 → 类对象：用转换构造函数
类对象 → 其他类型：用类型转换运算符


避免二义性：不要同时提供多个可以匹配同一转换的函数，否则会编译错误。


### 豆包的几道阅读程序写结果
所有题目都围绕两个核心机制展开，你只要把这两个搞懂，20 分稳拿：
1. 转换构造函数
定义：只有一个参数的构造函数
作用：允许将其他类型的值隐式转换为类对象
例子：Score s = 95; 等价于 Score s(95);
2. 类型转换运算符
定义：operator 目标类型() const { ... }
作用：允许将类对象隐式转换为其他类型的值
例子：cout << s << endl; 等价于 cout << (int)s << endl;
3. 必考陷阱
输出顺序：先执行构造函数输出，再执行类型转换输出
隐式转换触发时机：赋值、算术运算、函数参数传递、cout 输出
多个转换函数的优先级：精确匹配 > 标准转换 > 用户定义转换
