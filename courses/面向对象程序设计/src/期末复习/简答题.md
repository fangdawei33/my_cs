1. (简答题)
派生类对象的初始化不仅要考虑新增成员的初始化，还要考虑从基类继承来的成员的初始化，请写出派生类对象初始化的顺序。


1. 虚基类的构造函数（按派生列表中的声明顺序依次调用）。

2.非虚基类的构造函数（按派生列表中的声明顺序依次调用）。

3.新增成员对象的构造函数（按在类定义中的声明顺序依次调用）。

4.派生类自身的构造函数体。
派生类对象的初始化顺序仅由类定义时的声明顺序决定，与构造函数初始化列表中的书写顺序无关。


2. (简答题)
什么是绑定？绑定分几类？不同类别的绑定完成的阶段是什么？

定义：绑定是指将函数调用与具体的函数执行代码（内存地址）关联起来的过程。

分类与完成阶段：

静态绑定（早期绑定）：在程序的编译和链接阶段完成。通常根据对象的静态类型决定，如普通函数调用、函数重载。

动态绑定（晚期绑定）：在程序的运行阶段完成。C++中通过虚函数实现，根据指针或引用指向的实际对象类型来决定调用哪个函数。


3. (简答题)
类A派生出类B和类C，类C派生出类D，每个类中都有原型相同的成员函数show()，且类A不能实例化。正确定义类A、类B、类C及类D，达到如下要求：
void main()
{  A * p;
   B b;
   C c;
   D d;
   p=&b; p->show();//执行类B中的show()
   p=&c; p->show();//执行类C中的show()
   p=&d; p->show();//执行类D中的show()
}

```cpp
#include <iostream>
using namespace std;

class A {
public:
    virtual void show() = 0;
    virtual ~A() {}
};

class B : public A {
public:
    void show() {
        cout << "执行类B中的show()" << endl;
    }
};

class C : public A {
public:
    void show() {
        cout << "执行类C中的show()" << endl;
    }
};

class D : public C {
public:
    void show() {
        cout << "执行类D中的show()" << endl;
    }
};

```
