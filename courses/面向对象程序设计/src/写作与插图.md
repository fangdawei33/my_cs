# 继续写作与插图

## 笔记和图片放在哪里

这门课的源文件位于 `courses/面向对象程序设计/src/`。文章按主题分文件夹，旧笔记中的配图统一放在 `images/旧笔记/`。

```text
src/
├── SUMMARY.md
├── introduction.md
├── 类与对象/
│   ├── README.md
│   └── 对象的初始化方式.md
├── images/
│   ├── 旧笔记/
│   └── 我的新笔记/
└── ...
```

## 在新文章中插入图片

例如，给 `类与对象/初始化补充.md` 配一张图：

1. 把图片复制到 `src/images/我的新笔记/构造顺序.png`。
2. 在文章中写下面这行 Markdown。

```markdown
![构造函数调用顺序](../images/我的新笔记/构造顺序.png)
```

`../` 表示从文章所在的 `类与对象/` 返回上一层 `src/`，再进入 `images/`。如果文章直接放在 `src/` 下，就写 `images/我的新笔记/构造顺序.png`。

图片路径和文件名可以使用中文。图片文件要和 Markdown 一起提交到 GitHub。

## 把文章加入左侧目录

在 `SUMMARY.md` 的“类与对象”下面加入一行，两格缩进表示它属于这一章：

```markdown
- [类与对象](类与对象/README.md)
  - [初始化补充](类与对象/初始化补充.md)
```

也可以在 `类与对象/README.md` 中增加入口，方便从章节首页查找。

每篇文章用一个一级标题作为文章名，用二级、三级标题划分内容。右侧目录会根据这些小标题生成。

````markdown
# 初始化补充

## 一个例子

```cpp
class Example {
public:
    Example() = default;

```
````
