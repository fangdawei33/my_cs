# 函数指针

<!-- 原笔记：函数指针.md -->

函数指针也叫回调函数

```cpp
#include <iostream>
using namespace std;

// 先定义几个具体的“操作函数”
int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

// ⭐核心考点：带有3个形参的函数，其中第三个形参是函数指针
// 形参1: int x
// 形参2: int y
// 形参3: int (*func)(int, int) -> 这是一个指向函数的指针
void process(int x, int y, int (*func)(int, int)) {
    // 在函数体内部，调用传入的这个函数
    int result = func(x, y);
    cout << "运算结果是: " << result << endl;
}

int main() {
    int num1 = 10, num2 = 5;

    // 调用时，直接把函数名当作参数传进去
    cout << "执行加法: ";
    process(num1, num2, add);       // 传入加法函数

    cout << "执行减法: ";
    process(num1, num2, subtract);  // 传入减法函数

    return 0;
}

```
