# 函数参数传递的三种方式

<!-- 原笔记：函数参数传递的三种方式.md -->

c中有按值传递和按地址传递/按指针传递两种

c++有三种，多了一个引用传递

> 按地址/按指针传递

形参是指针变量

实参可以直接传地址，也可以传指针变量


```cpp


#include <iostream>

using namespace std;
    //第二种参数传递方式，按地址/指针传递
    void swap(int * p1,int *p2){
        int temp=*p1;
        *p1=*p2;
        *p2=temp;


    }
int main(){

    int a=10,b=2;
    int *p1,*p2;
    p1=&a,p2=&b;

    swap(p1,p2);  //传递指针变量

    cout<<"a="<<a<<"\n"<<"b="<<b<<endl;

    swap(&a,&b);   //直接传地址
    cout<<"a="<<a<<"\n"<<"b="<<b<<endl;

    int a1[1]={1};
    int b1[1]={2};
    swap(a1,b1);   //一维数组名相当于第一个元素的首地址，属于第二种将地址传递给函数的情况
    cout<<"a="<<a1[0]<<"\n"<<"b="<<b1[0]<<endl;


    return 0;
}
```


> 引用传递

形参类型是引用类型

实参可以直接传变量

形参相当于实参的别名

```cpp


#include <iostream>

using namespace std;

    void swap(int &p1,int &p2){
        int temp=p1;
        p1=p2;
        p2=temp;


    }
int main(){

    int a=10,b=2;


    swap(a,b);

    cout<<"a="<<a<<"\n"<<"b="<<b<<endl;



    return 0;
}
```
