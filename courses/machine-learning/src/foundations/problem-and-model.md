# 1.1 从问题到模型

> 💡 先说清楚输入、输出和评价方式，再选择模型。

## 一个简化问题

假设收集到一些练习记录：每条记录包括学习时长和练习得分。我们希望根据时长预测得分。

这里把学习时长记作输入 `x`，把得分记作目标 `y`。这只是用于说明概念的例子，实际得分还会受基础、题目难度等因素影响。

## 数据、模型、损失与优化

![数据、模型、损失与优化的关系](../images/learning-loop.svg)

| 部分 | 在例子中的含义 |
| --- | --- |
| 数据 | 已观察到的学习时长和得分 |
| 模型 | 用直线描述时长与得分的关系 |
| 损失 | 预测得分与实际得分之间的偏差 |
| 优化 | 调整直线的斜率和截距，让偏差减小 |

## 为什么要分训练集和测试集？

如果只检查模型在训练数据上的表现，就无法判断它是否记住了这些记录。测试集保留一部分未参与拟合的数据，用于评估模型对新样本的表现。

测试集应在最终评估时使用。反复根据测试结果选择模型，会让它逐渐失去作为独立检查的作用；调参时通常还需要验证集。
