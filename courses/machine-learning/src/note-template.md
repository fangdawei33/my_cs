# 笔记写作模板

## 推荐结构

新建一篇 Markdown 文件时，可以复制下面的结构：

```markdown
# 本节标题

## 这节课解决什么问题？

用一个具体例子说明动机。

## 核心概念

写出定义，再用自己的话解释。

## 推导或代码

记录关键步骤，以及每一步为什么成立。

## 实验与观察

记录设置、结果、局限，以及对应的实验文件。

## 还没想明白的问题

保留疑问，下一次学习时继续补充。

## 参考资料

附上课程、教材或原始论文链接。
```

## 加入左侧目录

在本课程的 `src/SUMMARY.md` 中增加链接；两个空格的缩进表示子章节：

```markdown
- [3. 新章节](new-chapter/README.md)
  - [3.1 第一节](new-chapter/first-note.md)
```

先创建链接对应的文件，再运行构建。文件夹名决定路径，目录中的排列决定阅读顺序。

## 图片与公式

图片放进本课程的 `src/images/`。从一级子目录里的文章引用时，使用相对路径：

```markdown
![图片说明](../images/example.svg)
```

本站采用 mdBook 内置的 MathJax 支持。块公式需要使用双反斜线分隔符：

```text
\\[ L = \frac{1}{n}\sum_{i=1}^{n}(\hat y_i-y_i)^2 \\]
```

行内公式使用 `\\(` 和 `\\)`。首次加载公式需要联网获取 MathJax；普通文字和代码不依赖它。
