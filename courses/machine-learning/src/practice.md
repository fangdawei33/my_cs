# 配套实验

## 下载实验文件

这里的实验文件会随网站一起发布，点击即可下载或查看：

- [线性回归 Notebook](experiments/linear-regression/study.ipynb)
- [线性回归 Python 脚本](experiments/linear-regression/train.py)

## 在自己的电脑运行

用 VS Code 打开项目，在资源管理器中找到这门课的 `experiments/linear-regression/`。

打开 `study.ipynb`，选择本地 Python 内核后逐个运行单元格。示例只使用标准库，不需要安装 NumPy 或 PyTorch。

也可以在项目根目录通过终端运行脚本：

```powershell
py courses/machine-learning/experiments/linear-regression/train.py
```

macOS、Linux 或其他 Python 环境，可将 `py` 换成对应的 `python3` 或 `python` 命令。

## 使用谁的计算资源？

网站负责展示笔记和提供文件下载，不会在网页里执行 Python。

- 选择本地 Python 内核：用自己电脑的 CPU 和内存。
- 选择远程内核：用远程服务器的资源。

## 怎么保存实验结论？

把观察到的损失变化、参数和疑问写回对应的 Markdown 笔记。Notebook 适合探索，笔记适合整理最终理解。
