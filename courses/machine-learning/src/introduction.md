## 这本书怎么读？

- 左侧是整门课的章节目录，可以展开或收起。
- 中间是当前笔记，右侧按小标题生成本节目录；窄屏时右侧目录会隐藏。
- 顶部可以搜索本书、切换阅读主题，或返回课程首页。

## 学习路线

先理解数据、模型、损失和优化之间的关系，再用线性回归走通一个完整例子。

| 阶段 | 要回答的问题 |
| --- | --- |
| 明确问题 | 输入是什么？希望预测什么？ |
| 建立模型 | 用什么函数表示输入与输出的关系？ |
| 定义损失 | 怎样衡量预测结果好不好？ |
| 优化参数 | 如何根据数据调整模型？ |
| 检验结果 | 对没见过的数据，模型表现如何？ |

## 笔记和实验放在哪里？

笔记正文在这门课的 `src/` 中；Notebook 和 Python 脚本统一放在 `experiments/` 中。

网站提供实验文件的下载。运行实验需要在自己的 VS Code、Jupyter 或远程计算环境中选择 Python 内核，使用该内核所在机器的资源。
