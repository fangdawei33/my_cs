# 机器学习实验

`.ipynb` 和 `.py` 统一按实验主题放置，不再分成 notebooks 和 examples 两个目录。

```text
experiments/
└── linear-regression/
    ├── study.ipynb
    └── train.py
```

用 VS Code 或 Jupyter 打开 Notebook，选择 Python 内核后运行。

本地内核使用自己电脑的资源；远程内核使用对应服务器的资源。本站只提供静态阅读与实验文件下载。

实验目录会复制到网站产物中。只放准备公开的学习材料，大型数据和模型放在项目外，通过说明文档记录获取方式。
