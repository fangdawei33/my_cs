# 首页原创插画

使用内置 image_gen 工具生成，作为本项目首页插画。原始生成文件保留在生成目录；网站使用本目录内的副本。

- `courses.png`：一起读书，课程笔记入口。
- `life.png`：草地野餐，生活入口。
- `resources.png`：书籍收藏，资源入口。
- `future.png`：纸飞机与星空，待开发入口。
- `riverside.png`：河边小憩，右侧展示窗口。

更换插画时，替换对应文件，或修改 index.html / web/gallery.json 的路径。README 封面仍放在根目录 assets/ 中，与这些插画分开管理。

## 生成提示词

### courses

Use case: illustration-story. Asset type: one square illustration for a circular portal icon on a Chinese personal learning website. Original cozy Japanese picture-book style, deliberately simple slightly wobbly dark cocoa ink outlines, matte pastel gouache and subtle paper grain, generous shapes, very cute but uncluttered. Recurring original characters: one small ivory cat with triangular ears and one honey-brown round-eared bear, tiny dot eyes, no clothing. Cream-white canvas with a complete round illustrated vignette centered, wide clean margin outside the circle. Fit all important subjects inside the central 80% so the website can display this image in a circle. No text, letters, UI, logos or watermark. Scene: the cat and bear sitting beside each other at a wooden study desk, an open notebook, a small closed laptop, a pencil and two little books; pale sage green backdrop and warm sunny window light. Clear close-up composition, calm joy in learning.
